## 弈心 · 围棋陪练 v0.1.0

Windows 本地围棋陪练。**双击启动，浏览器里出棋盘，全程离线。** 每一手都是本机 KataGo 的实时搜索，不是预置棋谱。

### 下载

解压后约 214 MB，含 KataGo 引擎与两个神经网络模型。解压到**不含中文的路径**（不要放 `Program Files`），双击 `启动围棋陪练.bat`。

### 运行要求

- Windows 10 / 11 x64
- 支持 OpenCL 的显卡；NVIDIA 独显体验最好，核显能跑但职业档明显变慢
- 约 600 MB 磁盘

首次启动会对你的显卡做一次 OpenCL 调优，可能等几分钟；调优结果会缓存，之后启动通常十几秒。

### 这一版有什么

- 陪练强度 9 档：15级 / 10级 / 5级 / 1级 / 业余1段 / 业余3段（Human SL 人类棋风），职业2段 / 职业5段 / 顶尖职业（b10c512，400 / 800 / 1600 visits）
- 对弈：19 / 13 / 9 路，中国 / 日本规则，执黑执白，让 2–9 子，贴目可调
- AI 提示（`H`）：A/B/C 三个候选点、胜率、目差、变化图
- 形势判断：地盘归属与目差预测
- 死活数子：双方停一手后自动标记死子，可手动修正
- AI 复盘：逐手胜率损失曲线、好棋/失误标记、点击跳转
- SGF 导出，结束对局自动保存到 `data/games/`

### 已知问题

- 仅 Windows。
- 档位名是引擎配置档位的名字，**不是段位证书**；需要正式评级请用 KataGo 官方 rating 工具。
- 核显环境下职业档单步可能超过 10 秒。
- 首次启动需要 OpenCL 调优，可能等几分钟。
